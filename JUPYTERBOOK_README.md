# JupyterBook for MediTwin Autumn Training 2026

## Instructions

1. Install JupyterBook

    ```bash
    pip install jupyter-book
    ```

2. Add your content to the `docs` folder as markdown,   Jupyter notebooks, or other supported formats.
3. Navigate to `docs` folder.
4. Start the JupyterBook server

    ```bash
    jupyter book start
    ```

For more information, refer to the [JupyterBook documentation](https://jupyterbook.org/stable/).
